# Trafira

**Прокси, DNS и маршрутизация на OpenWrt через LuCI.**

Выбирайте, какие сайты и устройства подключаются напрямую, через прокси, VPN или средства обхода DPI. Сервер, подписку либо VPN-интерфейс нужно настроить самостоятельно.

[Скачать](https://github.com/petrouspetr-pixel/trafira/releases/latest) · [Что нового](https://github.com/petrouspetr-pixel/trafira/releases)

## Возможности

- Правила по сайтам, IP-адресам, устройствам и готовым спискам сервисов.
- Подписки, отдельные прокси и настроенные WireGuard/AmneziaWG-интерфейсы; автоматический выбор доступного подключения.
- Свой DNS, DoH/DoT и резервные DNS-серверы.
- sing-box, Zapret, Zapret2 и ByeDPI с управлением компонентами из LuCI.
- Игровые пресеты, торренты и Wi-Fi Calling напрямую.
- Профили настроек, проверка маршрутизации, диагностика и мониторинг соединений.

## Установка

Нужны **OpenWrt 24.10 или новее с LuCI**, доступ в интернет и пакетный менеджер **opkg** или **apk**. Оставьте место во flash для Trafira, зависимостей и выбранной сборки sing-box.

Подключитесь к роутеру по SSH от `root` и выполните:

```sh
wget -O /tmp/trafira-install.sh https://raw.githubusercontent.com/petrouspetr-pixel/trafira/main/install.sh && sh /tmp/trafira-install.sh
```

Установщик использует последний релиз этого репозитория и выбирает формат пакетов. Затем откройте **Службы → Trafira** в LuCI.

Автоматического переноса из Podkop/Forkop нет: сохраните резервную копию вне роутера, удалите прежние пакеты и настройте Trafira заново.

## Первые шаги

1. В **Компонентах** проверьте наличие sing-box и установите дополнительные компоненты, если они нужны.
2. В **Секциях** выберите подключение и задайте сайты, списки или адреса для него.
3. В **Устройствах** при необходимости выберите клиентов, которые используют Trafira или обходят её.
4. Нажмите **Сохранить и применить**. Проверьте результат в **Дашборде** и **Диагностике**.

## Как пользоваться

| Вкладка | Для чего нужна |
| --- | --- |
| Секции | Подключения и условия маршрутизации |
| Серверы | Входящие подключения к роутеру |
| Устройства | Правила по IP, MAC-адресу или интерфейсу |
| Игровые пресеты | Магазины и учётные записи через выбранное подключение, остальной трафик выбранных адресов устройства напрямую |
| Проверка маршрутизации | Выберите устройство и введите сайт, чтобы узнать предполагаемый маршрут |
| Диагностика | Проверки DNS, sing-box, правил и журналов |
| Профили | Сохранение, сравнение, импорт и восстановление настроек |
| Компоненты | Установка и обновление Trafira и дополнительных пакетов |

**Игровые пресеты.** Для одного устройства можно добавить несколько платформ. Добавление, изменение и удаление применяются вместе кнопкой **Сохранить и применить**. **Сброс** отменяет несохранённые изменения. [Платформы и ограничения](docs/gaming-presets-sources.md).

**Проверка маршрутизации** анализирует настройки, а не открывает сайт и не проверяет его доступность. IP сайта определяется автоматически. Для HTTP подставляется порт 80, для TLS/QUIC — 443; введённый вручную порт сохраняется.

**В Настройках** можно включить торренты и Wi-Fi Calling напрямую. Первое относится к распознанным BitTorrent-соединениям, а не ко всему трафику торрент-клиента. Второе исключает из перехвата IPsec-соединения UDP 500/4500.

## Обновление

**Через LuCI:** Службы → Trafira → Компоненты → Проверить обновление → Обновить.

**Через SSH:** повторно выполните команду установки выше. Пользовательские настройки сохраняются. Перед обновлением сделайте резервную копию вне роутера. Экспортированные профили могут содержать пароли и ключи.

Если обновляетесь с 3.0.0–3.0.2 и устанавливали встроенный WARP, сначала снимите привязки его интерфейса в секциях и удалите компонент на прежней версии: `/usr/bin/trafira component_action warp remove`.

### Установка скачанных пакетов вручную

Скачайте из **одного релиза** пакеты `trafira`, `luci-app-trafira` и, если нужен русский интерфейс, `luci-i18n-trafira-ru`. Выберите `.ipk` для opkg или `.apk` для apk; сверьте контрольные суммы с `SHA256SUMS` того же релиза.

Создайте на роутере отдельную пустую папку `/tmp/trafira-update` и скопируйте в неё только выбранные пакеты одной версии. Выполните **одну** подходящую команду:

```sh
# Для opkg
opkg update && opkg install /tmp/trafira-update/*.ipk

# Для apk
apk update && apk add --allow-untrusted /tmp/trafira-update/*.apk
```

`--allow-untrusted` нужен для APK из этого проекта: они не подписаны ключом официального репозитория OpenWrt. Не смешивайте версии основного пакета и LuCI. После успешной установки включённую службу можно перезапустить:

```sh
/etc/init.d/trafira enabled && /etc/init.d/trafira restart
```

## Если что-то не работает

Запустите проверки в **Диагностике** и посмотрите журнал. При ошибке установки проверьте свободное место во flash. После обновления интерфейса обновите страницу с очисткой кэша браузера.

Для разбора проблемы подготовьте версии Trafira и OpenWrt, модель роутера, шаги воспроизведения и фрагмент журнала. Перед передачей журнала удалите из него пароли, ключи и закрытые ссылки подписок.
