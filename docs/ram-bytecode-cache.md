# Кэш байткода в RAM

Кэш ускоряет повторные обращения к четырём часто запускаемым модулям: диагностика, профили, игровые пресеты и управление версиями компонентов. Остальные модули и все импорты продолжают загружаться из исходников. Полной копии backend в RAM нет.

## Ограничения

- Общий объём содержимого файлов кэша — до **512 КиБ**; служебные данные файловой системы и рабочая память процесса в этот лимит не входят.
- Один исходник и один файл байткода — до **128 КиБ** каждый.
- В рабочей системе используется только tmpfs `/tmp`, каталог `/tmp/trafira-bytecode` принадлежит root и имеет права `0700`. При перезагрузке кэш исчезает.
- При доступной RAM менее 16 МиБ кэш не используется. Новые версии ucode дополнительно проверяют свободное место tmpfs; на старых любые ошибки выделения/записи также включают возврат к исходнику.
- Компиляция выполняется при первом подходящем запросе, текущим интерпретатором роутера. Готовый байткод не поставляется в APK/IPK; дополнительных действий при установке нет.

## Актуальность и отказоустойчивость

Сохранённая копия исходника сравнивается побайтно, поэтому изменение одинакового размера с прежней датой тоже обнаруживается. Импорты не кэшируются и читаются заново. Отпечаток исполняемого файла ucode меняет кэш после обновления интерпретатора.

Отдельная копия результата компиляции позволяет обнаружить повреждённый файл. Файлы публикуются под неблокирующей блокировкой; параллельный запрос сразу использует исходник. После аварийного завершения блокировку можно восстановить по PID и времени запуска процесса.

Если кэш занят, переполнен, повреждён, недоступен или компиляция не удалась, используется исходный модуль. Ошибка **уже запущенной команды** возвращается вызывающему коду без повторного выполнения: это предотвращает двойное применение настроек.

В окружении процесса кэш можно отключить через `TRAFIRA_BYTECODE_CACHE=0`. Параметры `TRAFIRA_BYTECODE_TEST_*` служат только для изолированных тестов с контрольным файлом в приватном каталоге `/tmp/trafira-bytecode-test-*`; они не являются настройками LuCI.

## Проверки

`tests/test_bytecode_cache.py` запускает настоящий ucode в одноразовых каталогах. Проверяются холодный и повторный запуск, изменение исходника и интерпретатора, повреждение/частичная запись, конкуренция, устаревшая блокировка, права, симлинки, ограничения и отсутствие повторного исполнения команды с ошибкой. Полный Backend CI повторяет тесты на исходном и уплотнённом коде.

`tools/benchmark-ucode.py` отдельно измеряет реальную команду `/usr/bin/trafira show_version` с отключённым и прогретым кэшем. Замеры GitHub runner не являются замерами скорости физического роутера.
