# Trafira

### Ваша сеть. Ваши правила.

**Больше контроля над OpenWrt — в привычном интерфейсе LuCI.** Выбирайте подключения для устройств и сайтов, настраивайте DNS, убирайте рекламу и смотрите, как работает ваша сеть. Сохраняйте удачные настройки в профили и применяйте несколько изменений одной кнопкой.

## Что нового по сравнению с Forkop

Trafira — независимое продолжение [Forkop](https://github.com/ushan0v/forkop). Подписки, каскадные подключения, IPv6 и управление компонентами были в исходном проекте. На этой основе в Trafira появились:

| Возможность | Что получаете вы |
| --- | --- |
| **Маршрутизация устройств** | Выбор клиентов по IP, MAC-адресу и интерфейсу; обнаруженные устройства доступны в списках LuCI. |
| **Игровые пресеты** | Steam, Epic Games, PlayStation и Xbox. Несколько платформ на одном устройстве работают вместе; добавление и удаление применяются общей кнопкой. |
| **Профили настроек** | До восьми сохранённых вариантов: сравнение изменений, переключение, импорт, экспорт и восстановление предыдущих настроек. |
| **Проверка маршрутизации** | Выберите устройство и введите домен: Trafira определит IP и объяснит, какое правило выбирает подключение или блокирует соединение. |
| **DNS-блокировка рекламы** | Действие блокировки в секциях работает до выдачи FakeIP и дополняется отклонением соответствующих соединений. |
| **Торренты и Wi-Fi Calling напрямую** | Отдельные переключатели для распознанного BitTorrent и IPsec-трафика звонков через Wi-Fi. |
| **Управление версиями sing-box** | Выбор совместимой версии установленного варианта и возможность закрепить её от обновления через Trafira. |
| **Маршрутизация приложений роутера** | Отдельная настройка для соединений самого OpenWrt с исключениями для служебного трафика. |
| **Расширенные настройки DNS** | Клиентский сертификат для собственного DoH, фильтр отдельных IPv6-проверок в режиме «Только IPv4» и сохранённые копии списков для запуска. |

Сравнение выполнено с [main Forkop на 17.10.2026](https://github.com/ushan0v/forkop/tree/dd483297be0ac4e52bb8f482e2640238b75af532). Это список дополнений Trafira, а не обещание поддержки всех функций сторонних компонентов.

### Меньше ожидания. Больше ясности.

Карточки дашборда видны сразу. Изменения игровых пресетов накапливаются до **«Применить»**, а **«Сброс»** отменяет несохранённые правки. При изменении только локальных правил Trafira повторно использует неизменившиеся наборы nftables, когда их безопасно сохранить, — без ожидания обновления всех удалённых списков.

## Установка одной командой

Нужны **OpenWrt 24.10 или новее, LuCI**, доступ в интернет и пакетный менеджер **opkg** или **apk**. Проверьте свободное место во flash: основной объём могут занимать sing-box и другие зависимости.

Подключитесь к роутеру по SSH от `root`:

```sh
wget -O /tmp/trafira-install.sh https://raw.githubusercontent.com/petrouspetr-pixel/trafira/main/install.sh && sh /tmp/trafira-install.sh
```

Установщик выбирает пакеты из последнего релиза **этого репозитория**. После установки откройте **Службы → Trafira**.

При переходе с Podkop/Forkop сначала сохраните резервную копию вне роутера. Автоматического переноса настроек нет; прежние пакеты нужно удалить и настроить Trafira заново.

## Настройте под себя

1. **Компоненты:** проверьте sing-box и установленные зависимости.
2. **Секции:** задайте подключение, домены, адреса или списки. Правила сверху проверяются раньше нижних.
3. **Устройства и игровые пресеты:** при необходимости настройте отдельных клиентов.
4. **Применить:** сохраните и активируйте подготовленные изменения. **Сохранить** записывает их без активации; **Сброс** отменяет несохранённое.
5. **Дашборд и диагностика:** проверьте состояние служб, DNS и правил.

**Проверка маршрутизации** объясняет конфигурацию, но не открывает сайт и не подтверждает его доступность. Для источника **«Сам роутер»** включите **Настройки → Маршрутизация приложений роутера** и нажмите **Применить**. Если данных недостаточно, результат укажет причину.

**Игровые пресеты** направляют магазины и службы учётных записей через выбранное подключение, остальной трафик указанных адресов устройства — напрямую. Общие домены платформ могут использоваться и игровым трафиком. [Платформы, источники и ограничения](docs/gaming-presets-sources.md).

**Торренты напрямую** работают для распознанных BitTorrent-соединений, не для любого трафика торрент-клиента. **Wi-Fi Calling напрямую** исключает из перехвата UDP 500/4500; работоспособность звонков также зависит от оператора и межсетевого экрана.

## Обновление

**Из LuCI:** Компоненты → Проверить обновление → Обновить.

**Без LuCI:** повторно выполните команду установки выше. Пользовательские настройки сохраняются. Перед обновлением сделайте резервную копию вне роутера; после обновления обновите страницу LuCI с очисткой кэша.

### Скачанные пакеты вручную

Из [одного релиза](https://github.com/petrouspetr-pixel/trafira/releases/latest) скачайте `trafira`, `luci-app-trafira` и при необходимости `luci-i18n-trafira-ru`: `.ipk` для opkg или `.apk` для apk. Сверьте файлы с `SHA256SUMS` этого же релиза.

Скопируйте только выбранные пакеты одной версии в отдельную пустую папку `/tmp/trafira-update`. Выполните подходящую команду:

```sh
# OpenWrt с opkg
opkg update && opkg install /tmp/trafira-update/*.ipk

# OpenWrt с apk
apk update && apk add --allow-untrusted /tmp/trafira-update/*.apk
```

`--allow-untrusted` требуется для APK проекта, не подписанных ключом официального репозитория OpenWrt. Не смешивайте версии backend и LuCI. Если после установки включённая служба требует перезапуска:

```sh
/etc/init.d/trafira enabled && /etc/init.d/trafira restart
```

Для старых установок 3.0.0–3.0.2 со встроенным WARP: перед обновлением снимите его привязки в секциях и удалите компонент на прежней версии: `/usr/bin/trafira component_action warp remove`.

## Удаление

Подключитесь к роутеру по SSH от `root` и запустите мастер:

```sh
wget -O /tmp/trafira-uninstall.sh https://raw.githubusercontent.com/petrouspetr-pixel/trafira/main/uninstall.sh && sh /tmp/trafira-uninstall.sh
```

Мастер покажет план и попросит подтверждение. По умолчанию **настройки, профили и компоненты сохраняются**. Можно отдельно выбрать очистку настроек Trafira и удаление sing-box, Zapret/Zapret2 и ByeDPI.

Перед удалением создаётся и проверяется резервная копия в `/root/trafira-uninstall-XXXXXX/settings.tar.gz`. Она остаётся даже при очистке настроек; скачайте её на компьютер, если планируете сброс или перепрошивку роутера. В копии могут находиться пароли и ключи.

Для предварительного просмотра без изменений:

```sh
sh /tmp/trafira-uninstall.sh --purge --remove-components --dry-run
```

Сетевые интерфейсы, настройки других программ и общие зависимости мастер не удаляет. При ошибке удаления пакетов очистка настроек останавливается; автоматического восстановления удалённых компонентов нет.

## Ошибка? Расскажите нам

Откройте [Issues](https://github.com/petrouspetr-pixel/trafira/issues) и опишите ожидаемое поведение, фактический результат и шаги повторения. Добавьте модель роутера, версии OpenWrt и Trafira и нужный фрагмент журнала из **Диагностики**.

Перед публикацией удалите пароли, ключи, адреса частных серверов, ссылки подписок и другие персональные данные. **Не прикладывайте полный профиль или конфигурацию без проверки:** экспорт может содержать секреты.

## Назначение и правовая информация

Trafira предназначена для администрирования сетей, которыми вы вправе управлять. Используйте сетевые подключения, DNS и дополнительные компоненты только для законных задач и с соблюдением применимых ограничений доступа. Здесь не приводятся инструкции по доступу к запрещённым ресурсам и не обещается его предоставление.

Zapret, Zapret2 и ByeDPI — отдельные сторонние проекты. Trafira сохраняет интеграцию для управления ими; пакеты устанавливаются отдельно из источников их разработчиков. Эти компоненты не входят в APK/IPK Trafira.

В РФ действуют ограничения на рекламу средств доступа к ресурсам с ограниченным доступом ([Федеральный закон № 281-ФЗ от 31.07.2025](https://www.consultant.ru/document/cons_doc_LAW_511068/)). Meta Platforms Inc. в части реализации социальных сетей Facebook и Instagram включена в [перечень экстремистских организаций Минюста РФ](https://minjust.gov.ru/ru/documents/7822/); её соответствующая деятельность запрещена в РФ. Решение не распространяется на WhatsApp. Упоминания приведены для правового информирования.
